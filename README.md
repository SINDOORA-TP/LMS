# LMS - Learning Management System 🚀

A comprehensive, state-of-the-art Learning Management System built with a powerful Laravel backend and a cross-platform mobile frontend. This project is designed to deliver a seamless educational experience for both administrators and students.

🌍 **Live Website / Admin Portal:** [https://lms.abinaasananthaguruji.com/](https://lms.abinaasananthaguruji.com/)

## ✨ Key Features
*   **Premium Admin Dashboard:** A fully custom, modern admin panel with dynamic stats and resource management.
*   **Course Management:** Create, edit, and organize courses, modules, and video lessons with ease.
*   **User & Enrollment System:** Comprehensive tracking of student progress and enrollments.
*   **Security Violation Tracking:** Built-in mechanisms to detect and report user security violations directly to the admin.
*   **Payments Integration:** PhonePe payment gateway integration for course purchases.
*   **Mobile App Frontend:** A beautifully designed frontend tailored for mobile users.

## 🛠️ Technology Stack
*   **Backend:** Laravel (PHP), Filament Admin Panel, MySQL
*   **Frontend:** Flutter / Dart
*   **Payment Gateway:** PhonePe
*   **Infrastructure:** Hostinger, Firebase
